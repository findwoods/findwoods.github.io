🧪 题目 I.1 - 结构推断题详解

题目概述

推断化合物 A (分子式 C₆H₁₀) 和化合物 B 的结构。

已知条件：
  • ¹H NMR: 1.71 δ (单峰, 3H) 和 2.57 δ (单峰, 2H)
  • IR: 2947 cm⁻¹ 强峰，3000以上无峰
  • A + O₃ → B
  • A + H₂/Pd → C₆H₁₂

工具1: 不饱和度计算

通过分子式计算不饱和度，判断分子中双键和环的数量。

公式： 不饱和度 = (2n + 2 - H) / 2，其中 n 为碳原子数，H 为氢原子数
计算： C₆H₁₀ → 饱和应为 C₆H₁₄，缺少4个H → 不饱和度 = 4/2 = 2
步骤: 0/4

工具2: ¹H NMR 核磁共振分析

通过化学位移和裂分模式判断氢环境。

1.71 δ (单峰, 3H)： 连在双键上的甲基 -CH₃
2.57 δ (单峰, 2H)： 双键附近的亚甲基 -CH₂-
关键推断： 分子高度对称，实际有2个CH₃(6H)和2个CH₂(4H)
步骤: 0/3

工具3: IR 红外光谱分析

通过特征吸收峰判断官能团。

2947 cm⁻¹ 强峰： 饱和 C-H 伸缩振动 (sp³杂化)
3000以上无峰： 关键证据! 双键上没有氢 → 四取代烯烃
步骤: 0/3

工具4: 催化加氢反应分析

通过加氢产物确定双键和环的数量。

反应： A (C₆H₁₀) + H₂/Pd → C₆H₁₂
关键推断： 完全饱和应为C₆H₁₄，产物C₆H₁₂仍有1个不饱和度
结论： H₂/Pd只还原双键不还原环 → A有1个环 + 1个双键
步骤: 0/4

工具5: 化合物A结构确定

综合所有证据，确定化合物A的结构。

综合证据：
✓ 1个环 + 1个双键
✓ 双键上无H (四取代)
✓ 有CH₃和CH₂基团
✓ 高度对称结构
步骤: 0/5

工具6: 臭氧氧化反应 (Ozonolysis)

O₃切断双键，将化合物A转化为化合物B。

反应原理： 臭氧(O₃)切断C=C双键，双键碳变成羰基(C=O)
产物B特征： IR显示1713 cm⁻¹强峰 → 酮基
步骤: 0/6

🎯 最终答案

化合物 A

结构： 1,2-二甲基环丁烯 (1,2-Dimethylcyclobutene)

特征： 四元环 + 四取代双键 + 两个甲基

化合物 B

结构： 2,5-己二酮 (2,5-Hexanedione)

化学式： CH₃-C(=O)-CH₂-CH₂-C(=O)-CH₃

来源： 由A经臭氧氧化切断双键生成
