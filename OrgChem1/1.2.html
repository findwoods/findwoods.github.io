🧪 题目 I.2 - 碳谱与对称性推断

题目概述

推断化合物 C (分子式 C₈H₁₂)、D 和 E 的结构。

已知条件：
  • ¹³C NMR: 只有2个峰 - 38.7 ppm (CH₂) 和 127.6 ppm (CH)
  • C + 2 equiv H₂ → D (D的NMR只有1个峰)
  • C + O₃/Zn → E (E的碳谱有2个峰: 36 ppm和202 ppm)

工具1: 不饱和度计算

C₈H₁₂： 饱和应为C₈H₁₈，缺少6个H → 不饱和度 = 3
步骤: 0/3

工具2: 加氢反应分析 → 推导化合物D

C + 2H₂ → D： 消耗2分子H₂ → 有2个双键
D的NMR只有1个峰： 所有碳等价 → 高度对称的环辛烷
步骤: 0/6

工具3: 化合物C结构 - 1,5-环辛二烯

结构要求： 八元环 + 2个双键，且只有2种碳环境
答案： 1,5-Cyclooctadiene (1,5-环辛二烯)
步骤: 0/5

工具4: 臭氧氧化 → 化合物E (丁二醛)

反应： C + O₃/Zn → E
原理： 切断两个双键，每个双键碳变成醛基(-CHO)
E的碳谱： 36 ppm (CH₂) 和 202 ppm (CHO醛基碳)
步骤: 0/7

🎯 最终答案

化合物 C

结构： 1,5-环辛二烯 (1,5-Cyclooctadiene)

特征： 八元环 + 2个对称分布的双键，只有2种碳环境

化合物 D

结构： 环辛烷 (Cyclooctane)

特征： 完美对称的八元环，NMR只有1个信号

化合物 E

结构： 丁二醛 (Butanedial)

化学式： O=CH-CH₂-CH₂-CH=O

来源： 由C经臭氧氧化切断两个双键生成
