这是一个关于有机合成方法学、反应机理判定以及试剂特性的深度解析文档。我将完全忽略篇幅限制，用最详尽、最缓慢、最基础的方式，结合您要求的化学符号表示法，为您从头到尾、逐字逐句地拆解这份文档的每一层含义。

第一部分：吉尔曼试剂 (R2CuLiR_2CuLiR2​CuLi) 与碳-碳键的形成

这部分内容位于文档的第一页顶部，是有机合成中构建碳骨架（Carbon Skeleton）的核心工具。

1. 吉尔曼试剂的化学本质

  • 化学名称：二烷基铜锂 (Lithium Dialkylcuprate)，通称吉尔曼试剂 (Gilman Reagent)。
  • 核心结构：R2CuLiR_2CuLiR2​CuLi。
    • 这里的 RRR 代表一个碳基团（可以是链状的，也可以是环状的）。
    • CuCuCu 是金属铜。
    • LiLiLi 是金属锂。
  • 可视化的结构理解： 想象一个带负电荷的中心复合物 [R−Cu−R]−[R-Cu-R]^-[R−Cu−R]−，旁边伴随着一个带正电荷的锂离子 Li+Li^+Li+。在这个结构中，铜原子 (CuCuCu) 像一只手，同时抓住了两个碳基团 (RRR)。

    [R−Cu−R]−Li+[R - Cu - R]^- Li^+ [R−Cu−R]−Li+

    由于铜 (CuCuCu) 的电负性比碳 (CCC) 低，碳原子带上了部分负电荷。这使得这个试剂中的碳变得非常有攻击性（即亲核性），它渴望去攻击带正电的地方。

2. 吉尔曼试剂的制备过程

文档中的第一个反应方程式展示了如何制造这个试剂：

2RLi+CuI→醚(ether)R2CuLi+LiI2 RLi + CuI \xrightarrow{醚 (ether)} R_2CuLi + LiI 2RLi+CuI醚(ether)​R2​CuLi+LiI

  • 原料 1：RLiRLiRLi (有机锂试剂)
    • 这是非常活泼的试剂，其中碳直接连在锂上。你需要 2份 (2 equivalents) 的 RLiRLiRLi。
  • 原料 2：CuICuICuI (碘化亚铜)
    • 这是铜的来源。你需要 1份 的 CuICuICuI。
  • 溶剂：醚 (etheretherether)
    • 通常指的是乙醚 (Et2OEt_2OEt2​O) 或四氢呋喃 (THFTHFTHF)。溶剂的作用是稳定这个活泼的金属有机化合物，防止它在空气中燃烧或分解。
  • 过程详解：
    1. 当你把 2 个分子的 RLiRLiRLi 加入到 1 个分子的 CuICuICuI 中时。
    2. 第一个 RRR 基团上去，把 III（碘）踢走，形成 R−CuR-CuR−Cu（这是中间态，不稳）。
    3. 第二个 RRR 基团再上去，结合在铜上，形成带负电的 [R2Cu]−[R_2Cu]^-[R2​Cu]− 离子。
    4. 最终产物就是 R2CuLiR_2CuLiR2​CuLi。
  • RRR 基团的适用范围： 文档明确指出，这里的 RRR 可以是：
    • Alkyl (烷基)：普通的单键碳链，如 CH3−CH_3-CH3​− 或 CH3CH2−CH_3CH_2-CH3​CH2​−。
    • Vinylic (乙烯基)：含有双键的碳，如 CH2=CH−CH_2=CH-CH2​=CH−。
    • Aryl (芳基)：苯环类的结构，如 6C环。

3. 吉尔曼试剂的核心反应：偶联反应

这是文档中最重要的反应式，用于连接两个碳链：

R2CuLi+R′−X⟶R−R′R_2CuLi + R'-X \longrightarrow R-R' R2​CuLi+R′−X⟶R−R′

让我们拆解这个反应的每一个参与者和步骤：

  • 攻击者 (亲核试剂)：R2CuLiR_2CuLiR2​CuLi
    • 它提供了一个 RRR 基团。虽然它身上有两个 RRR，但通常只有一个 RRR 会被利用到最终产物中，另一个 RRR 会随着铜变成废料浪费掉。
  • 被攻击者 (亲电试剂)：R′−XR'-XR′−X
    • R′R'R′：这是你想延长的另一段碳链。
    • XXX：这是卤素 (Halogen)，充当“离开基团” (Leaving Group)。文档注明 XXX 可以是 ClClCl (氯)、BrBrBr (溴) 或 III (碘)。
  • 产物：R−R′R-R'R−R′
    • 这是一个新的 碳-碳单键 (C−CC-CC−C)。原本的 RRR 链和 R′R'R′ 链连接在了一起。
  • 副产物 (通常省略不写，但为了理解原理需要知道)：
    • R−CuR-CuR−Cu (剩下一个 RRR 在铜上)。
    • LiXLiXLiX (锂离子和卤素结合)。

数值示例与细节解释： 假设你想合成一条 5 个碳长的链，你手头有一个 2 个碳的卤代烃和一个 3 个碳的链。

  • 你制备了 (CH3CH2CH2)2CuLi(CH_3CH_2CH_2)_2CuLi(CH3​CH2​CH2​)2​CuLi （带有 3 个碳的 RRR 基团）。
  • 你有一个 CH3CH2−BrCH_3CH_2-BrCH3​CH2​−Br （带有 2 个碳的 R′R'R′ 基团，连接着溴）。
  • 反应：这两个家伙在醚溶剂中混合。
  • 结果：CH3CH2CH2−CH2CH3CH_3CH_2CH_2 - CH_2CH_3CH3​CH2​CH2​−CH2​CH3​。
    • 注意：这里形成的新键连接了 3C链 和 2C链，构成了 5C链。
  • 重要限制：吉尔曼试剂虽然强大，但它对底物 R′−XR'-XR′−X 有要求。通常 R′−XR'-XR′−X 最好是 一级卤代烃 (1∘1^\circ1∘ alkyl halide)、乙烯基卤代烃 (vinyl−Xvinyl-Xvinyl−X) 或 芳基卤代烃 (aryl−Xaryl-Xaryl−X)。它通常不用于二级或三级卤代烃的取代反应，因为会发生消除副反应。

第二部分：合成帮助——形成 C-C 键和 C-X 键

这部分总结了有机合成中“如何搭建乐高积木（碳骨架）”和“如何安装接口（卤素）”的方法。

4. 形成 C-C 键 (C-C Bonds) 的两种主要策略

文档列出了两种延长碳链的方法：

策略 A：使用吉尔曼试剂 (Gilman Reagent)

  • 描述：Gilman Reagent to add RRR to R′R'R′。
  • 解析：这就是我们刚刚在上一节详细讨论的内容。它的优势在于可以保持双键的几何构型（如果 RRR 或 R′R'R′ 中有双键的话），并且可以连接芳环（6C环）。

策略 B：使用炔烃阴离子 (SN2S_N2SN​2 反应)

这是一个非常经典且强大的反应，分为三步走：

  1. 原料：末端炔烃 (AlkyneAlkyneAlkyne)。结构必须是 R−C≡C−HR-C \equiv C-HR−C≡C−H。注意，三键的一端必须有一个 HHH (氢)，这个氢具有酸性。
  2. 第一步：去质子化 (Deprotonation)
    • 试剂：NaNH2NaNH_2NaNH2​ (氨基钠)。
    • 溶剂：液态氨 (liq.NH3liq. NH_3liq.NH3​)。
    • 过程：NH2−NH_2^-NH2−​ 是一个极强的碱。它会像拔草一样，把炔烃末端的那个 HHH 拔掉。
    • 方程式：R−C≡C−H+NH2−→R−C≡C−+NH3R-C \equiv C-H + NH_2^- \rightarrow R-C \equiv C^- + NH_3R−C≡C−H+NH2−​→R−C≡C−+NH3​。
    • 产物：R−C≡C−R-C \equiv C^-R−C≡C− (炔碳负离子)。这个碳带着负电荷，非常渴望攻击正电荷中心，是一个极好的亲核试剂。
  3. 第二步：亲核取代 (SN2S_N2SN​2 Reaction)
    • 反应物：让上面生成的 R−C≡C−R-C \equiv C^-R−C≡C− 与一个 一级卤代烃 (1∘1^\circ1∘ halide, 结构为 R′−CH2−XR'-CH_2-XR′−CH2​−X) 反应。
    • 机理：SN2S_N2SN​2 (双分子亲核取代)。炔负离子从背面攻击连接卤素的碳，把卤素 XXX 踢走。
    • 方程式：R−C≡C−+R′−CH2−X⟶R−C≡C−CH2−R′R-C \equiv C^- + R'-CH_2-X \longrightarrow R-C \equiv C-CH_2-R'R−C≡C−+R′−CH2​−X⟶R−C≡C−CH2​−R′。
    • 结果：你在两个碳片段之间建立了一个新的 C−CC-CC−C 单键，而且分子中保留了一个 三键 (C≡CC \equiv CC≡C)。这非常有用，因为三键以后还可以变成双键或单键。

5. 形成 C-X 键 (C-X Bonds) 的四种方法

这一节教你如何在碳链上引入卤素（Cl,Br,ICl, Br, ICl,Br,I），通常引入卤素是为了后续能进行其他反应（因为烷烃太稳定了，很难直接反应）。

方法 A：HX 加成到烯烃 (HX to add to alkene)

  • 原料：烯烃 (C=CC=CC=C 双键)。
  • 试剂：HXHXHX (如 HCl,HBr,HIHCl, HBr, HIHCl,HBr,HI)。
  • 反应：C=CC=CC=C 双键打开，一个碳拿走 HHH，另一个碳拿走 XXX。

    R−CH=CH2+H−Br⟶R−CH(Br)−CH3R-CH=CH_2 + H-Br \longrightarrow R-CH(Br)-CH_3 R−CH=CH2​+H−Br⟶R−CH(Br)−CH3​

  • 规则 (马氏规则)：HHH 会加到氢多的那个碳上，XXX 会加到氢少的那个碳（取代基多的碳）上。这叫 Markovnikov 加成。

方法 B：HX 加成到炔烃 (HX to add to alkyne)

  • 原料：炔烃 (C≡CC \equiv CC≡C 三键)。
  • 试剂：HXHXHX。
  • 反应：
    • 加 1当量 HXHXHX：三键变双键，引入一个 XXX。 (C≡C→C=CXC \equiv C \rightarrow C=CXC≡C→C=CX)
    • 加 2当量 HXHXHX：三键变单键，引入两个 XXX 到同一个碳上。 (C≡C→CH2−CX2C \equiv C \rightarrow CH_2-CX_2C≡C→CH2​−CX2​)
  • 这也是遵循马氏规则的。

方法 C：使用 NBS 进行烯丙位溴化

  • 试剂：NBSNBSNBS (N-溴代丁二酰亚胺)。这是一种特殊的提供 BrBrBr (溴) 的试剂。
  • 目标位置：烯丙位 (Allylic position)。
    • 定义：烯丙位是指 紧邻 双键碳原子的那个碳位置。
    • 结构示意：C=C−C∗C=C-C^*C=C−C∗ (带星号的就是烯丙位)。
  • 反应：

    R−CH=CH−CH3+NBS⟶R−CH=CH−CH2−BrR-CH=CH-CH_3 + NBS \longrightarrow R-CH=CH-CH_2-Br R−CH=CH−CH3​+NBS⟶R−CH=CH−CH2​−Br

  • 特点：这个反应 保留双键 不动，只在旁边的碳上贴一个 BrBrBr。这是因为反应中间经过了一个共振稳定的自由基。

方法 D：使用 X2X_2X2​ 和光照 (hvhvhv)

  • 原料：烷烃 (只有单键的 C−CC-CC−C)。
  • 试剂：X2X_2X2​ (卤素单质，如 Cl2,Br2Cl_2, Br_2Cl2​,Br2​)。
  • 条件：hvhvhv (光照) 或加热。这是为了产生自由基。
  • 反应机理：自由基取代。
  • 选择性规则 (重要细节)：
    • 文档指出：添加 XXX 到 最受取代 (most substituted) 的位置。意思是，如果分子里有三级碳（连3个C）、二级碳（连2个C）和一级碳，卤素优先去三级碳。
    • 注意：BrBrBr (溴) 比 ClClCl (氯) 的选择性高得多 (More selective)。
    • 解释：如果你用 Cl2Cl_2Cl2​，它像个疯子，会乱加在各种位置，产物很杂。如果你用 Br2Br_2Br2​，它非常挑剔，几乎只加在最稳定的那个碳（三级碳 > 二级碳 > 一级碳）上。所以在合成中，想精准加卤素，通常用 Br2/hvBr_2/hvBr2​/hv。

第三部分：将羟基 (-OH) 转化为离开基团 (LG)

这部分位于第一页中部。 背景知识：羟基 (−OH-OH−OH) 是一个极差的离开基团。你不能直接用亲核试剂去踢走 −OH-OH−OH。你必须先把它“整容”，变成一个容易脱落的基团，才能进行后续的 SN2S_N2SN​2 或消除反应。

6. 方法一：TsCl / Pyridine (甲苯磺酰氯 / 吡啶)

  • 试剂：TsClTsClTsCl (Tosyl Chloride) 和 Pyridine (作为溶剂和碱)。
  • 条件：通常在低温 (cold) 下进行。
  • 转化结果：−OH-OH−OH 变成了 −OTs-OTs−OTs (Tosylate)。

    R−OH→TsClR−OTsR-OH \xrightarrow{TsCl} R-OTs R−OHTsCl​R−OTs

  • 关键细节 - 立体化学：构型保持 (Retention of stereochemistry)。
    • 解释：这个反应只发生在氧原子 (OOO) 上，断的是 O−HO-HO−H 键，没有 断开 C−OC-OC−O 键。因为碳原子没有被打扰，所以如果原本 −OH-OH−OH 是朝上的（楔形），变成 −OTs-OTs−OTs 后依然朝上。
  • 用途：−OTs-OTs−OTs 是一个极好的离开基团，效果类似卤素，之后可以被其他亲核试剂通过 SN2S_N2SN​2 反应踢走。

7. 方法二：SOCl2SOCl_2SOCl2​ / Ether (二氯亚砜 / 醚)

  • 试剂：SOCl2SOCl_2SOCl2​ (Thionyl Chloride)。
  • 转化结果：−OH-OH−OH 被替换成了 −Cl-Cl−Cl (氯)。

    R−OH→SOCl2R−ClR-OH \xrightarrow{SOCl_2} R-Cl R−OHSOCl2​​R−Cl

  • 机理：SN2S_N2SN​2 机制。
  • 关键细节 - 立体化学：构型翻转 (Inversion of stereochemistry)。
    • 解释：在反应的最后一步，Cl−Cl^-Cl− 从背面攻击碳原子，把中间体踢走。这就像大风吹翻雨伞一样，如果原本 −OH-OH−OH 朝上，产物中的 −Cl-Cl−Cl 会朝下。
  • 限制：不能用于三级醇 (Tertiary electrophile)。因为三级碳位阻太大，SN2S_N2SN​2 反应无法发生。

8. 方法三：PBr3PBr_3PBr3​ / Ether (三溴化磷 / 醚)

  • 试剂：PBr3PBr_3PBr3​ (Phosphorus Tribromide)。
  • 转化结果：−OH-OH−OH 被替换成了 −Br-Br−Br (溴)。

    R−OH→PBr3R−BrR-OH \xrightarrow{PBr_3} R-Br R−OHPBr3​​R−Br

  • 机理：SN2S_N2SN​2 机制。
  • 关键细节 - 立体化学：构型翻转 (Inversion of stereochemistry)。同上，产物的立体构型与原料相反。
  • 限制：不能用于三级醇。同样是因为位阻阻碍了 SN2S_N2SN​2 攻击。

第四部分：反应预测 —— SN1/SN2/E1/E2S_N1 / S_N2 / E1 / E2SN​1/SN​2/E1/E2

这是有机化学中最复杂、最让学生头疼的部分。文档从第一页底部一直延伸到第二页，提供了详细的决策树。

基本概念复习：

  • SN2S_N2SN​2：双分子亲核取代。亲核试剂从背面撞击，离开基团同时滚蛋。一步完成。不喜欢拥挤（位阻）。
  • SN1S_N1SN​1：单分子亲核取代。离开基团先自己滚蛋，形成碳正离子 (C+C^+C+)，然后亲核试剂再慢悠悠过来。两步完成。需要碳正离子稳定（三级碳最好）。
  • E2E2E2：双分子消除。碱抓走旁边的氢 (HHH)，离开基团 (XXX) 同时滚蛋，形成双键 (C=CC=CC=C)。一步完成。需要强碱。
  • E1E1E1：单分子消除。伴随 SN1S_N1SN​1 发生。离开基团先走，形成 C+C^+C+，然后弱碱拿走 HHH 形成双键。

9. 预测逻辑：一级烷基 (1∘1^\circ1∘ Alkyl)

结构：R−CH2−XR-CH_2-XR−CH2​−X。碳原子很空旷，容易被攻击。

  • 默认情况：SN2S_N2SN​2。
    • 因为位阻小，亲核试剂容易进去。
  • 例外情况 (E2)：
    • 如果使用 t−BuO−t-BuO^-t−BuO− (叔丁醇钾)。
    • 解释：t−BuO−t-BuO^-t−BuO− 是一个“大胖子”强碱。它太胖了，挤不进碳原子的背面去做 SN2S_N2SN​2。但它可以作为碱，在外面轻松抓走一个氢原子，从而引发 E2E2E2 消除反应。
  • 特殊情况：β\betaβ-分支 (Beta-branching)
    • 定义：虽然连卤素的碳是一级碳，但它隔壁的碳 (Beta碳) 连了很多东西，非常拥挤（例如新戊基结构）。这会像堵门一样阻碍 SN2S_N2SN​2。
    • 分支情形 A：如果遇到 好亲核试剂且是弱碱 (Good nucleophiles, weak bases)。
      • 例如：I−,RS−I^-, RS^-I−,RS−。
      • 结果：依然是 SN2S_N2SN​2 占主导。
    • 分支情形 B：如果遇到 强碱 (Strong bases)。
      • 例如：OH−,RO−OH^-, RO^-OH−,RO−。
      • 结果：E2E2E2 占主导。因为背面攻击太挤了，强碱宁愿去拔氢。

10. 预测逻辑：二级烷基 (2∘2^\circ2∘ Alkyl)

结构：R2CH−XR_2CH-XR2​CH−X。这是最纠结的区域，通常是 SN2S_N2SN​2 和 E2E2E2 的战场。因为二级碳正离子不够稳定，所以通常不走 SN1/E1S_N1/E1SN​1/E1 (除非溶剂极性极强且无亲核试剂)。

  • 一般原则：SN2S_N2SN​2 vs E2E2E2。
  • 如何让 SN2S_N2SN​2 获胜？
    • 使用 好亲核试剂 且 弱碱 (Good nucleophile, weak base)。
    • 例子：I−,Br−,CH3COO−I^-, Br^-, CH_3COO^-I−,Br−,CH3​COO−。
    • 因为它们不爱拔氢（弱碱），只想进攻碳（亲核），所以发生取代。
  • 如何让 E2E2E2 获胜？
    • 使用 强碱 (Strong base)。
    • 例子：OH−,CH3O−,CH3CH2O−OH^-, CH_3O^-, CH_3CH_2O^-OH−,CH3​O−,CH3​CH2​O−。
    • 强碱会迅速拔掉 β−H\beta-Hβ−H (隔壁碳上的氢)，引发消除反应生成烯烃。

11. 预测逻辑：三级烷基 (3∘3^\circ3∘ Alkyl)

结构：R3C−XR_3C-XR3​C−X。碳原子被三个基团包围，像个堡垒，背面完全堵死。绝不可能发生 SN2S_N2SN​2。

  • 情形 A：没有强碱 (Without strong base)
    • 试剂通常是弱亲核试剂/弱碱，如 H2O,ROHH_2O, ROHH2​O,ROH（溶剂解反应）。
    • 过程：离开基团 XXX 只能自己先离开，留下一个三级碳正离子 (3∘C+3^\circ C^+3∘C+)。这个离子很稳定。
    • 结果：SN1S_N1SN​1 和 E1E1E1 的混合物。
      • SN1S_N1SN​1：溶剂分子撞上 C+C^+C+。
      • E1E1E1：溶剂分子拿走旁边的 HHH。
      • 通常加热有利于 E1E1E1。
  • 情形 B：有强碱 (With strong base)
    • 试剂如 OH−,RO−OH^-, RO^-OH−,RO−。
    • 结果：仅发生 E2E2E2。
    • 原因：虽然亲核试剂进不去（不能 SN2S_N2SN​2），但强碱可以直接在外部拔走表面的氢原子。
    • 速率：文档强调，E2 的速率与碱的浓度成正比 (Rate=k[Base][Substrate]Rate = k[Base][Substrate]Rate=k[Base][Substrate])。增加碱浓度会加速反应。
    • 总结：强碱极大地促进 E2E2E2，特别是对于高度分支（拥挤）的烷基。

第五部分：试剂分类清单 (The Toolkit)

这部分位于第二页中部，是判断上述反应路径的关键字典。必须背诵理解。

12. 强碱 (Strong Bases)

  • 列表：
    • OH−OH^-OH− (氢氧根)
    • RO−RO^-RO− (醇负离子，如 CH3O−,EtO−CH_3O^-, EtO^-CH3​O−,EtO−)
    • NH2−NH_2^-NH2−​ (氨基负离子)
  • 重要注释：“体积大的东西” (Bulky things)，例如 t−BuO−t-BuO^-t−BuO−。
    • 虽然它们可能不是传统意义上的“强”（因为在某些溶剂中表现不同），但在有机反应中，它们通常作为 碱 (Base) 行动。
    • 原因：它们太胖了，塞不进碳原子的缝隙去做亲核取代 (SubstitutionSubstitutionSubstitution)，所以只能做消除 (EliminationEliminationElimination)。

13. 好亲核试剂 (Good Nucleophiles)

这些家伙善于攻击碳原子。

  • I−I^-I− (碘离子)：卤素中的王者。
    • 原因：碘原子很大，电子云松散（易极化），像一团软棉花，很容易变形成键。另外它对应的共轭酸 (HIHIHI) 是强酸，说明 I−I^-I− 是极弱的碱，非常稳定。
  • P 和 N 亲核试剂：含磷 (PPP) 和氮 (NNN) 的化合物，如 PR3,NH3,N3−PR_3, NH_3, N_3^-PR3​,NH3​,N3−​。
  • CN−CN^-CN− (氰根)：中等强度的亲核试剂。

14. 组合分类 (用于做决断)

  • 好亲核试剂 & 强碱：
    • OH−,RO−,NH2−OH^-, RO^-, NH_2^-OH−,RO−,NH2−​。
    • 行为：容易导致 E2E2E2（特别是在 2∘/3∘2^\circ/3^\circ2∘/3∘ 碳上）或 SN2S_N2SN​2（在 1∘1^\circ1∘ 碳上）。
  • 好亲核试剂 & 弱碱：
    • Cl−,Br−,I−Cl^-, Br^-, I^-Cl−,Br−,I− (卤素离子)。
    • N3−N_3^-N3−​ (叠氮根)。
    • SSS (硫) 和 PPP (磷) 的亲核试剂 (如 HS−,RS−HS^-, RS^-HS−,RS−)。
    • 行为：这是 SN2S_N2SN​2 的完美搭档。因为它们不爱拔氢（不做 E2E2E2），只想进攻碳。
  • 弱亲核试剂 & 弱碱：
    • ROO−ROO^-ROO− (羧酸根，虽然带负电，但共振分散了电荷，不活泼)。
    • H2OH_2OH2​O (水)。
    • ROHROHROH (醇)。
    • 行为：它们太懒了。通常只能等待碳正离子形成 (SN1/E1S_N1 / E1SN​1/E1)。

15. 离开基团 (Leaving Groups) 的好坏

反应能不能发生，取决于这个“前任”愿不愿意走。

  • 好离开基团 (Good LG)：
    • RSO3−RSO_3^-RSO3−​ (磺酸根，如 OTs−OTs^-OTs−)。非常稳定，极好的 LG。
    • I−I^-I− (碘) > Br−Br^-Br− (溴) > Cl−Cl^-Cl− (氯)。
    • H2OH_2OH2​O (水)。当醇羟基 (OHOHOH) 质子化变成 H2O+H_2O^+H2​O+ 时，水是一个中性且稳定的好 LG。
  • 坏离开基团 (Bad LG)：
    • F−F^-F− (氟)：电负性太强，键太短太强，不愿意断。
    • RCO2−RCO_2^-RCO2−​。
    • CN−CN^-CN−。
    • 极差离开基团 (Worst 5)：
      • −OH-OH−OH (羟基)
      • MeO−MeO^-MeO− (甲氧基)
      • EtO−EtO^-EtO− (乙氧基)
      • RO−RO^-RO− (一般醇基)
      • NH2−NH_2^-NH2−​
    • 策略：如果遇到这最后 5 个，绝对不能 直接写 SN2S_N2SN​2 把它们踢走。必须先通过化学反应（如加酸质子化，或用 TsClTsClTsCl）将它们转化为好离开基团。

16. 溶剂的影响 (Solvents)

  • 质子溶剂 (Protic solvents)：
    • 特征：分子中有 O−HO-HO−H 或 N−HN-HN−H 键，能提供氢键。
    • 例子：ROHROHROH (醇), Formic acid (甲酸), Acetic acid (乙酸), H2OH_2OH2​O。
    • 影响：它们会像毯子一样包裹住阴离子（亲核试剂），降低其活性。不利于 SN2S_N2SN​2。有利于 SN1S_N1SN​1（因为能稳定碳正离子）。
  • 非质子溶剂 (Aprotic solvents)：
    • 特征：有极性，但没有活泼氢 (OH/NHOH/NHOH/NH)。
    • 例子：
      • DMSODMSODMSO (二甲基亚砜)
      • DMFDMFDMF (二甲基甲酰胺)
      • Acetone (丙酮)
      • Acetonitrile (乙腈)
      • HMPAHMPAHMPA
    • 影响：它们不包裹阴离子，让亲核试剂“裸露”在外，活性极高。极大地加速 SN2S_N2SN​2 反应。

第六部分：狄尔斯-阿德尔反应 (Diels Alder)

这部分位于文档末尾，是一个完全不同类型的反应，称为“环加成反应”。

17. 反应概览

  • 类型：[4+2] 环加成。
  • 目的：构建 六元环 (6-membered ring)。这是合成环状分子的神器。
  • 通式：

    Diene(二烯体)+Dienophile(亲二烯体)→ΔCyclohexene(环己烯衍生物)Diene (二烯体) + Dienophile (亲二烯体) \xrightarrow{\Delta} Cyclohexene (环己烯衍生物) Diene(二烯体)+Dienophile(亲二烯体)Δ​Cyclohexene(环己烯衍生物)

18. 反应组分详解

  • 二烯体 (Diene)：
    • 必须是一个 共轭二烯 (Conjugated Diene)。
    • 结构：C=C−C=CC=C-C=CC=C−C=C。含有两个双键，中间隔着一个单键。
    • 构象要求：必须处于 s-cis 构象（两个双键在单键的同侧，像个字母 C），这样才能弯过来咬住对方。
  • 亲二烯体 (Dienophile)：
    • 这是一个含有一个双键 (C=CC=CC=C) 或三键 (C≡CC \equiv CC≡C) 的分子。
    • 通常连有 吸电子基团 (EWG, 如 C=O,CNC=O, CNC=O,CN) 会让反应更快。

19. 电子流动与产物结构

  • 机理：协同反应 (Concerted mechanism)。所有键的断裂和生成是同时发生的，像一个圆圈舞。
  • 变化统计：
    • 断裂了 3个 π\piπ 键（二烯体 2 个，亲二烯体 1 个）。
    • 生成了 1个新的 π\piπ 键（在原本二烯体的两个双键中间）。
    • 生成了 2个新的 σ\sigmaσ 键（将二烯体的头尾与亲二烯体连接）。
  • 视觉化结果： 文档中的图示非常清晰。 左边：一个开口的“C”形 4碳链（二烯） + 一个 2碳双键（亲二烯）。 箭头：加热。 右边：一个闭合的 6C环，环里有一个双键。

全文核心逻辑总结

这份文档其实是在教你如何像建筑师一样思考分子合成：

  1. 地基：用 R2CuLiR_2CuLiR2​CuLi 或 炔烃负离子 把碳链加长。
  2. 装修：用 HX,NBS,X2HX, NBS, X_2HX,NBS,X2​ 在碳链上安装功能性接口（卤素）。
  3. 改造：如果遇到不好用的接口（−OH-OH−OH），用 TsCl,SOCl2TsCl, SOCl_2TsCl,SOCl2​ 把它换成好用的接口。
  4. 组装：通过 SN2S_N2SN​2 把模块拼起来，或者用 E2E2E2 制造双键。
  5. 避坑指南：利用 1∘,2∘,3∘1^\circ, 2^\circ, 3^\circ1∘,2∘,3∘ 的规则和试剂的强弱表，避免发生不想要的副反应（比如想做取代却发生了消除）。
