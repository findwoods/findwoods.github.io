1. 热力学第一定律基础回顾

  • 基本定律：能量守恒

    • 热力学第一定律的核心是能量守恒。
    • 系统的内能（Internal Energy, UUU）是系统状态的函数。一个系统的状态由其状态变量（如压力 PPP、体积 VVV、温度 TTT）确定。对于一个简单系统，通常只需要两个独立变量就能确定其状态。
    • 内能是状态函数（State Function）：只要系统的始末状态确定，内能的变化量 ΔU\Delta UΔU 就是确定的，与从初始状态到最终状态所经过的路径无关。
    • 内能的微小变化量 dUdUdU 是一个全微分（Exact Differential）。

  • 热与功：路径函数

    • 与内能不同，热（Heat, QQQ）和功（Work, WWW）都是路径函数（Path Functions）。它们的值依赖于系统状态变化的具体路径，而不是仅仅取决于始末状态。
    • 因此，它们的微小变化量用 δQ\delta QδQ 和 δW\delta WδW 表示，而不是 dQdQdQ 和 dWdWdW。

  • 热力学第一定律的数学表达式

    • 对于一个有限的过程，其表达式为：

      ΔU=Q+W\Delta U = Q + W ΔU=Q+W

      • 细节解释：这是演讲者口述的表达式。需要注意的是符号约定。

    • 符号约定（Sign Convention）：

      • QQQ：系统吸收的热量为正 (Q>0Q > 0Q>0)；系统放出的热量为负 (Q<0Q < 0Q<0)。
      • WWW：外界对系统做的功为正 (W>0W > 0W>0)；系统对外界做的功为负 (W<0W < 0W<0)。演讲者此处定义“WWW是系统做的功”，但其公式 W=−PextdVW = -P_{ext}dVW=−Pext​dV 暗示了 WWW 代表外界对系统做的功，因为系统膨胀时 dV>0dV>0dV>0，而系统对外做功，此时 WWW 为负值。这是一个常见的混淆点，后续计算将根据具体公式进行澄清。

2. 功的计算与可逆过程

  • 膨胀功（Expansion Work）

    • 在本次讨论中，主要关注的是体积变化引起的膨胀功。

    • 其计算公式为：

      δW=−PextdV\delta W = -P_{ext} dV δW=−Pext​dV

      • PextP_{ext}Pext​：外界压力（External Pressure）。
      • dVdVdV：系统的体积微小变化量。
      • 细节解释：如果系统膨胀（dV>0dV > 0dV>0），系统对外界做功，根据此公式 WWW 为负值。这与上述 W>0W>0W>0 为外界对系统做功的约定一致。

  • 可逆过程（Reversible Process）

    • 可逆过程是一个理想化的过程，它进行得无限缓慢，过程中每一步系统都无限接近于平衡态。

    • 在可逆过程中，系统的内压力（Internal Pressure, PPP）与外界压力 PextP_{ext}Pext​ 时刻相等。

      Pext=PinternalP_{ext} = P_{internal} Pext​=Pinternal​

    • 因此，在可逆过程中，功的计算公式可以写为：

      δW=−PdV\delta W = -P dV δW=−PdV

      • 细节解释：这使得我们可以用系统自身的状态变量（PPP）来计算功，这是进行积分计算的前提。

3. P-V图与不同热力学路径

  • P-V图

    • 我们通常使用压力-体积图（P-V图）来描述系统状态的变化。这是一个方便且常见的二维表示方法。
    • 图上的一个点代表系统的一个确定的平衡态。一条曲线代表一个热力学过程（路径）。

  • 路径依赖性的图示

    • 假设系统从状态1（P1,V1,T1P_1, V_1, T_1P1​,V1​,T1​）变化到状态2（P2,V2,T1P_2, V_2, T_1P2​,V2​,T1​）。
    • 路径A：可逆等温膨胀 (Reversible Isothermal Expansion)
      • 系统沿着一条等温线（T=T1T=T_1T=T1​为常数）从点1直接膨胀到点2。
      • 此路径下，压力与体积的乘积近似为常数（对于理想气体而言）。
    • 路径B+C：分步过程
      • 路径B：恒压膨胀（Isobaric Expansion）：系统首先在恒定压力 P1P_1P1​ 下膨胀，体积从 V1V_1V1​ 变为 V2V_2V2​。此时状态变为 (P1,V2,T3P_1, V_2, T_3P1​,V2​,T3​)。
      • 路径C：恒容冷却（Isochoric Cooling）：接着，系统在恒定体积 V2V_2V2​ 下冷却，压力从 P1P_1P1​ 降到 P2P_2P2​，温度也相应变化（最终回到T1T_1T1​）。
    • 结论：
      • 尽管两条路径的始末状态相同（或相似），但它们在P-V图下面积（代表功的大小）是不同的。
      • 因此，功 WWW 和热 QQQ 的值都取决于所选择的路径。
      • 然而，内能变化 ΔU\Delta UΔU 在所有路径中都是完全相同的，因为它只取决于始末状态。

4. 理想气体内能与路径计算实例

  • 理想气体的关键特性

    • 对于理想气体（Ideal Gas），其内能 UUU 仅仅是温度 TTT 的函数，与体积 VVV 或压力 PPP 无关。
    • 原因：理想气体模型忽略了分子间的相互作用力，因此系统的势能为零，内能只包含分子的动能，而宏观上动能只与温度有关。
    • 注意：对于真实气体，由于存在分子间相互作用，内能同时是温度和体积的函数。

  • 路径计算分析（以单原子理想气体为例）

    • 路径A（可逆等温膨胀）

      • 始末温度相同（T1→T1T_1 \rightarrow T_1T1​→T1​）。
      • 因为内能只取决于温度，所以内能变化为零。

        ΔUA=0\Delta U_A = 0 ΔUA​=0

    • 路径B（恒压膨胀：(P1,V1,T1)→(P1,V2,T3)(P_1, V_1, T_1) \rightarrow (P_1, V_2, T_3)(P1​,V1​,T1​)→(P1​,V2​,T3​)）

        WB=−∫V1V2PextdV=−P1∫V1V2dV=−P1(V2−V1)W_B = - \int_{V_1}^{V_2} P_{ext} dV = -P_1 \int_{V_1}^{V_2} dV = -P_1 (V_2 - V_1) WB​=−∫V1​V2​​Pext​dV=−P1​∫V1​V2​​dV=−P1​(V2​−V1​)

          ΔUB=CV,m(T3−T1)=32R(T3−T1)\Delta U_B = C_{V,m} (T_3 - T_1) = \frac{3}{2} R (T_3 - T_1) ΔUB​=CV,m​(T3​−T1​)=23​R(T3​−T1​)

5. 特殊过程：真空绝热膨胀

  • 实验设置（焦耳膨胀）

    • 一个装有气体的容器，活塞被销钉固定。
    • 活塞外部是真空，即外界压力 Pext=0P_{ext} = 0Pext​=0 kPa。
    • 整个系统是绝热的（Adiabatic），意味着系统与外界没有热量交换。

  • 过程分析

    • 突然拔掉销钉，气体向真空自由膨胀。
    • 热量交换 QQQ：因为系统是绝热的。

      Q=0Q = 0 Q=0

    • 功的计算 WWW：因为气体是向真空膨胀，Pext=0P_{ext} = 0Pext​=0。

      W=−∫PextdV=−∫(0)dV=0W = - \int P_{ext} dV = - \int (0) dV = 0 W=−∫Pext​dV=−∫(0)dV=0

    • 内能变化 ΔU\Delta UΔU：根据热力学第一定律。

      ΔU=Q+W=0+0=0\Delta U = Q + W = 0 + 0 = 0 ΔU=Q+W=0+0=0

  • 结论

    • 理想气体的真空绝热膨胀过程，其内能不变。
    • 由于理想气体的内能只取决于温度，ΔU=0\Delta U = 0ΔU=0 意味着 ΔT=0\Delta T = 0ΔT=0。
    • 因此，理想气体的真空绝热膨胀也是一个等温过程（Isothermal Process）。
    • 重要提醒：等温过程不一定没有热量交换（如可逆等温膨胀就需要吸热），但真空绝热膨胀这个特殊过程恰好既绝热又等温（对理想气体而言）。

6. 内能的微观解释：统计热力学视角

  • 内能的统计定义

    • 宏观的内能 UUU 是系统所有可能的微观能量状态 EjE_jEj​ 的统计平均值。

      U=∑jPjEjU = \sum_j P_j E_j U=j∑​Pj​Ej​

      • EjE_jEj​：系统处于第 jjj 个微观量子态时的能量（能级）。
      • PjP_jPj​：系统处于该微观量子态的概率。

    • 概率 PjP_jPj​ 主要取决于温度 TTT，通常与玻尔兹曼因子（Boltzmann factor）成正比：

      Pj∝e−Ej/kBT=e−βEj(其中 β=1/kBT)P_j \propto e^{-E_j / k_B T} = e^{-\beta E_j} \quad (\text{其中 } \beta = 1/k_B T) Pj​∝e−Ej​/kB​T=e−βEj​(其中 β=1/kB​T)

    • 能级 EjE_jEj​ 取决于系统的物理参数，如粒子数 NNN 和体积 VVV。改变体积会改变能级的数值。

    • EjE_jEj​ 的物理来源包括：分子的平动能、转动能、振动能以及分子间的相互作用势能。

  • 热力学第一定律的微观推导

    • 对内能 UUU 的表达式进行全微分：

      dU=d(∑jPjEj)=∑j(EjdPj+PjdEj)dU = d\left(\sum_j P_j E_j\right) = \sum_j (E_j dP_j + P_j dE_j) dU=d(j∑​Pj​Ej​)=j∑​(Ej​dPj​+Pj​dEj​)

    • 各项的物理意义：

      1. ∑jPjdEj\sum_j P_j dE_j∑j​Pj​dEj​：这一项代表在保持各能级占据概率 PjP_jPj​ 不变的情况下，由于系统参数（如体积 VVV）变化导致的能级 EjE_jEj​ 自身的变化。这对应于系统与外界的功交换。

        ∑jPjdEj=(∑jPj∂Ej∂V)dV=δWrev=−PdV\sum_j P_j dE_j = \left(\sum_j P_j \frac{\partial E_j}{\partial V}\right) dV = \delta W_{rev} = -P dV j∑​Pj​dEj​=(j∑​Pj​∂V∂Ej​​)dV=δWrev​=−PdV

      2. ∑jEjdPj\sum_j E_j dP_j∑j​Ej​dPj​：这一项代表在保持能级 EjE_jEj​ 不变的情况下，由于与外界热量交换导致温度变化，从而引起各能级占据概率 PjP_jPj​ 的重新分布。这对应于系统吸收的热量。

        ∑jEjdPj=δQrev\sum_j E_j dP_j = \delta Q_{rev} j∑​Ej​dPj​=δQrev​

    • 最终关联：

      dU=∑jEjdPj⏟δQrev+∑jPjdEj⏟δWrevdU = \underbrace{\sum_j E_j dP_j}_{\delta Q_{rev}} + \underbrace{\sum_j P_j dE_j}_{\delta W_{rev}} dU=δQrev​j∑​Ej​dPj​​​+δWrev​j∑​Pj​dEj​​​

7. 焓（Enthalpy）的引入：恒压过程的便利工具

  • 引入动机
    • 在化学和生物学中，许多过程是在恒定压力下进行的（例如，在敞口烧杯中进行的反应，大气压恒定）。
  • 推导过程
    • 从热力学第一定律微分形式出发，考虑一个可逆过程：

      dU=δQrev+δWrev=δQrev−PdVdU = \delta Q_{rev} + \delta W_{rev} = \delta Q_{rev} - P dV dU=δQrev​+δWrev​=δQrev​−PdV

    • 移项得到热量的表达式：

      δQrev=dU+PdV\delta Q_{rev} = dU + P dV δQrev​=dU+PdV

    • 当压力 PPP 恒定时，我们可以进行如下数学处理：

      (δQrev)P=dU+d(PV)(因为 d(PV)=PdV+VdP，恒压下 dP=0)(\delta Q_{rev})_P = dU + d(PV) \quad (\text{因为 } d(PV) = P dV + V dP \text{，恒压下 } dP=0) (δQrev​)P​=dU+d(PV)(因为 d(PV)=PdV+VdP，恒压下 dP=0)

    • 合并微分项：

      (δQrev)P=d(U+PV)(\delta Q_{rev})_P = d(U + PV) (δQrev​)P​=d(U+PV)

  • 焓的定义
    • 上式表明，在恒压可逆过程中，系统吸收的热量等于一个新物理量 U+PVU+PVU+PV 的全微分。
    • 我们定义这个新的状态函数为焓（Enthalpy），符号为 HHH。

      H≡U+PVH \equiv U + PV H≡U+PV

  • 焓的意义
    • 焓也是一个状态函数，因为它由状态函数 U,P,VU, P, VU,P,V 组合而成。
    • 对于在恒定压力下发生的任何过程，焓的变化量 ΔH\Delta HΔH 等于系统在此过程中吸收或放出的热量 QPQ_PQP​。

      ΔH=QP\Delta H = Q_P ΔH=QP​

    • 应用：化学反应的反应热通常在恒压下测量，因此测得的数值就是反应的焓变 ΔrH\Delta_r HΔr​H。

8. 焓、热容及其关系

  • 热容回顾与定义

      CP,m=(∂H∂T)P=(∂(U+RT)∂T)P=(∂U∂T)P+RC_{P,m} = \left(\frac{\partial H}{\partial T}\right)_P = \left(\frac{\partial (U+RT)}{\partial T}\right)_P = \left(\frac{\partial U}{\partial T}\right)_P + R CP,m​=(∂T∂H​)P​=(∂T∂(U+RT)​)P​=(∂T∂U​)P​+R

9. 焓变的计算：相变过程

  • 总焓变的计算原则
    • 由于焓是状态函数，我们可以将一个复杂的过程分解为若干个简单的、易于计算的步骤，总的焓变等于所有分步焓变之和。
  • 示例：将1摩尔冰从0K加热到高于沸点的TfT_fTf​

    • 分步计算：

      1. 加热冰：将冰从 000 K 加热到熔点 TmT_mTm​ (273.15 K)。

        ΔH1=∫0TmCp,冰(T)dT\Delta H_1 = \int_{0}^{T_m} C_{p, \text{冰}}(T) dT ΔH1​=∫0Tm​​Cp,冰​(T)dT

      2. 熔化：在恒定温度 TmT_mTm​ 下，冰完全融化成水。

        ΔH2=ΔfusH\Delta H_2 = \Delta_{fus}H ΔH2​=Δfus​H

        • ΔfusH\Delta_{fus}HΔfus​H 是摩尔熔化焓（Molar Enthalpy of Fusion）。

      3. 加热水：将液态水从熔点 TmT_mTm​ 加热到沸点 TbT_bTb​ (373.15 K)。

        ΔH3=∫TmTbCp,水(T)dT\Delta H_3 = \int_{T_m}^{T_b} C_{p, \text{水}}(T) dT ΔH3​=∫Tm​Tb​​Cp,水​(T)dT

      4. 汽化：在恒定温度 TbT_bTb​ 下，水完全汽化成蒸汽。

        ΔH4=ΔvapH\Delta H_4 = \Delta_{vap}H ΔH4​=Δvap​H

        • ΔvapH\Delta_{vap}HΔvap​H 是摩尔汽化焓（Molar Enthalpy of Vaporization）。

      5. 加热蒸汽：将水蒸气从沸点 TbT_bTb​ 加热到最终温度 TfT_fTf​。

        ΔH5=∫TbTfCp,蒸汽(T)dT\Delta H_5 = \int_{T_b}^{T_f} C_{p, \text{蒸汽}}(T) dT ΔH5​=∫Tb​Tf​​Cp,蒸汽​(T)dT

    • 总焓变为各步之和：

      ΔHtotal=ΔH1+ΔH2+ΔH3+ΔH4+ΔH5\Delta H_{total} = \Delta H_1 + \Delta H_2 + \Delta H_3 + \Delta H_4 + \Delta H_5 ΔHtotal​=ΔH1​+ΔH2​+ΔH3​+ΔH4​+ΔH5​

10. 反应焓变与赫斯定律

  • 反应焓变的定义

    • 反应焓（Enthalpy of Reaction, ΔrH\Delta_r HΔr​H）是指在恒定压力下，当反应物按照化学计量系数完全转化为产物时，体系的焓变。

    • 对于一个通用反应 aA+bB→cCaA + bB \rightarrow cCaA+bB→cC：

      ΔrH=H产物−H反应物=c⋅Hm(C)−[a⋅Hm(A)+b⋅Hm(B)]\Delta_r H = H_{\text{产物}} - H_{\text{反应物}} = c \cdot H_m(C) - [a \cdot H_m(A) + b \cdot H_m(B)] Δr​H=H产物​−H反应物​=c⋅Hm​(C)−[a⋅Hm​(A)+b⋅Hm​(B)]

      • HmH_mHm​ 代表摩尔焓。

  • 赫斯定律（Hess's Law）

    • 定律陈述：一个化学反应的反应焓，只与反应的始末状态有关，而与反应的途径无关。如果一个反应可以分几步进行，则总反应的焓变等于各分步反应焓变的代数和。
    • 示例：计算金刚石 →\rightarrow→ 石墨的焓变

      • 直接测量此反应的焓变非常困难。

      • 我们可以通过测量它们的燃烧焓（Enthalpy of Combustion）来间接计算：

        1. C(金刚石) + O2(g)→CO2(g)ΔH1O_2(g) \rightarrow CO_2(g) \quad \Delta H_1O2​(g)→CO2​(g)ΔH1​
        2. C(石墨) + O2(g)→CO2(g)ΔH2O_2(g) \rightarrow CO_2(g) \quad \Delta H_2O2​(g)→CO2​(g)ΔH2​

      • 我们想求的反应是：C(金刚石) →\rightarrow→ C(石墨)

      • 可以通过 (反应1) - (反应2) 得到目标反应：

        ΔH金刚石→石墨=ΔH1−ΔH2\Delta H_{\text{金刚石}\rightarrow\text{石墨}} = \Delta H_1 - \Delta H_2 ΔH金刚石→石墨​=ΔH1​−ΔH2​

        • 细节解释：通过设计一个可测量的热化学循环，可以计算出难以直接测量的反应的焓变。

11. 反应焓变的温度依赖性（基尔霍夫定律）

  • 问题：已知一个反应在温度 T1T_1T1​ 下的反应焓 ΔrH(T1)\Delta_r H(T_1)Δr​H(T1​)，如何计算它在另一个温度 T2T_2T2​ 下的反应焓 ΔrH(T2)\Delta_r H(T_2)Δr​H(T2​)？
  • 基尔霍夫定律（Kirchhoff's Law）

    • 利用赫斯定律构建一个热化学循环：

      1. 路径一：反应物在 T1T_1T1​ 反应生成产物，然后将产物加热到 T2T_2T2​。
      2. 路径二：先将反应物加热到 T2T_2T2​，然后在 T2T_2T2​ 进行反应。

    • 两条路径的总焓变相等，由此可推导出：

      ΔrH(T2)=ΔrH(T1)+∫T1T2ΔCpdT\Delta_r H(T_2) = \Delta_r H(T_1) + \int_{T_1}^{T_2} \Delta C_p dT Δr​H(T2​)=Δr​H(T1​)+∫T1​T2​​ΔCp​dT

    • 其中，ΔCp\Delta C_pΔCp​ 是产物与反应物的恒压热容之差：

      ΔCp=∑产物νiCp,i−∑反应物νjCp,j\Delta C_p = \sum_{\text{产物}} \nu_i C_{p,i} - \sum_{\text{反应物}} \nu_j C_{p,j} ΔCp​=产物∑​νi​Cp,i​−反应物∑​νj​Cp,j​

      • ν\nuν 是化学计量系数。

12. 思想实验：如何计算地球上的化石燃料总量？

  • 问题提出

    • 如何估算地球上所有化石燃料（Fossil Fuels），即以还原形式存在的碳（如煤、石油、天然气）的总量？

  • 核心逻辑与化学原理

    1. 来源追溯：化石燃料本质上是古代生物质（植物、藻类等）经过漫长地质作用形成的。
    2. 光合作用：这些生物质中的碳最初来源于大气中的二氧化碳（CO2CO_2CO2​），通过光合作用（Photosynthesis）被固定下来。
    3. 关键反应：光合作用的简化化学反应式为：

      nCO2+nH2O→光能(CH2O)n(碳水化合物)+nO2nCO_2 + nH_2O \xrightarrow{\text{光能}} (CH_2O)_n (\text{碳水化合物}) + nO_2 nCO2​+nH2​O光能​(CH2​O)n​(碳水化合物)+nO2​

    4. 地球大气的演化：地球早期大气中几乎没有游离的氧气（O2O_2O2​）。现在大气中约21%的氧气，绝大部分是亿万年来光合作用的产物。
    5. 化学计量关系：根据上述反应式，每在地球上通过光合作用固定1摩尔的碳原子形成生物质，就会同时向大气中释放1摩尔的氧气分子。

  • 计算方法

    1. 计算大气中氧气的总量：
      • 地球表面积 AAA 已知。
      • 标准大气压 PatmP_{atm}Patm​ 已知（约 1.01×1051.01 \times 10^51.01×105 Pa）。
      • 大气层总质量 MatmM_{atm}Matm​ 可以通过 Matm=(Patm⋅A)/gM_{atm} = (P_{atm} \cdot A) / gMatm​=(Patm​⋅A)/g 估算。
      • 大气中氧气的质量分数（约23%）或摩尔分数（约21%）已知。
      • 通过这些数据，可以计算出大气中 O2O_2O2​ 的总质量或总摩尔数。
    2. 推算化石燃料总量：
      • 假设大气中所有的 O2O_2O2​ 都来自于光合作用对 CO2CO_2CO2​ 的还原。
      • 那么，地球上以还原形式（生物质和化石燃料）存在的碳的总摩尔数，应该约等于大气中 O2O_2O2​ 的总摩尔数。
      • 细节：这个估算忽略了现存的活体生物量，但与埋藏了亿万年的化石燃料相比，活体生物量是一个非常小的部分，因此这个估算在数量级上是合理的。

  • 结论

    • 通过计算大气中氧气的总量，可以对地球上化石燃料的总储量给出一个相当精确的科学估算。这个方法比实地勘探要宏观和根本得多。
